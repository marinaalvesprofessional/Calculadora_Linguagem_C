# 🧮 Calculadora em C — 20 Operações Matemáticas

Projeto desenvolvido em linguagem C com o objetivo de aplicar conceitos fundamentais de programação por meio da criação de uma calculadora com 20 operações matemáticas diferentes.

O programa possui um menu interativo que permite ao usuário selecionar a operação desejada, informar os valores e visualizar o resultado diretamente no terminal.

---

## 📌 Sobre o projeto

A calculadora foi desenvolvida como atividade prática da disciplina **Algoritmos e Pensamento Computacional**, com foco na utilização de funções, estruturas condicionais, estruturas de repetição e bibliotecas da linguagem C.

O projeto reúne operações matemáticas básicas e avançadas em um único programa, permitindo praticar a organização e a reutilização de código.

## ⚙️ Funcionalidades

A calculadora possui 20 operações:

| Nº | Operação | Descrição |
|---|---|---|
| 01 | Soma | Adiciona dois números. |
| 02 | Subtração | Subtrai dois números. |
| 03 | Multiplicação | Multiplica dois números. |
| 04 | Divisão | Divide dois números. |
| 05 | Potência | Calcula um número elevado a outro. |
| 06 | Raiz quadrada | Calcula a raiz quadrada de um número. |
| 07 | Porcentagem | Calcula a porcentagem de um valor. |
| 08 | Fatorial | Calcula o fatorial de um número inteiro. |
| 09 | Resto da divisão | Retorna o resto de uma divisão inteira. |
| 10 | Logaritmo | Calcula o logaritmo natural. |
| 11 | Seno | Calcula o seno de um ângulo. |
| 12 | Cosseno | Calcula o cosseno de um ângulo. |
| 13 | Tangente | Calcula a tangente de um ângulo. |
| 14 | Valor absoluto | Retorna o valor absoluto de um número. |
| 15 | Arredondamento | Arredonda um número para o inteiro mais próximo. |
| 16 | Piso | Arredonda um número para baixo. |
| 17 | Teto | Arredonda um número para cima. |
| 18 | Inverso | Calcula o inverso de um número. |
| 19 | Média | Calcula a média de dois números. |
| 20 | Exponencial | Calcula o número de Euler elevado a um valor. |

## 💻 Tecnologias utilizadas

- **Linguagem C:** desenvolvimento da lógica e das operações matemáticas.
- **Biblioteca stdio.h:** entrada e saída de dados.
- **Biblioteca math.h:** funções matemáticas, como potência, raiz quadrada, seno, cosseno e logaritmo.

## 🧠 Conceitos de programação aplicados

Durante o desenvolvimento, foram utilizados os seguintes conceitos:

- Funções: organização das 20 operações em funções independentes.
- Variáveis: armazenamento dos valores informados pelo usuário.
- Estruturas condicionais: utilização de `if`, `else` e `switch`.
- Estrutura de repetição: utilização de `do...while` para manter o menu funcionando.
- Entrada e saída de dados: utilização de `scanf()` e `printf()`.
- Tratamento de erros: verificações para situações como divisão por zero e valores negativos em operações que não os permitem.

## ▶️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

**2. Entre na pasta do projeto:**

```bash
cd SEU-REPOSITORIO
```

**3. Compile o código:**

```bash
gcc calculadora.c -o calculadora -lm
```

**4. Execute o programa:**

No Windows:

```bash
calculadora.exe
```

No Linux:

```bash
./calculadora
```

> É necessário ter um compilador C, como o GCC, instalado no computador.
